# Proposals

Designs written to be reviewed before any code: each one says what is known (checked in the code), what is proposed, what is left to decide. Nothing in them is implemented unless it says so.

| Proposal | Roadmap item |
| --- | --- |
| [web.md](web.md) | basic web: a placeholder site and `/helper` serving opensim-helpers, configured from `/etc/opensim` |
| [parcel-name.md](parcel-name.md) | a better way to name the parcel of a new region |
| [home-region.md](home-region.md) | users created get the default region as home |
| [bulk-avatars.md](bulk-avatars.md) | bulk avatar creation from a list |
| [config-import.md](config-import.md) | configuration import from `Robust.ini` and `OpenSim.ini` |
| [gettext.md](gettext.md) | localization of the setup and the launcher |
| [installation-agnostic.md](installation-agnostic.md) | the tools work with any OpenSim installation |
